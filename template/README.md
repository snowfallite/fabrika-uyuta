# Фабрика Уюта — Style Kit

Дизайн-система сайта https://fabrika-comfort-vologda.base44.app/ в виде готового к использованию набора.

## Состав
- `STYLE-GUIDE.md` — палитра (HSL и HEX), шрифты, типографика, компоненты, анимации
- `src/index.css` — токены и утилиты (`.glass`, `.reveal`, `.lift-hover` …), без изменений из исходника
- `tailwind.config.js` — конфиг из исходника (в `content` добавлен `./demo/**/*.html`)
- `dist/styles.css` — собранный минифицированный CSS
- `demo/index.html` — главная: все секции в порядке `Home.jsx`, на точных классах ваших компонентов
- `demo/admin.html` — админ-панель (каркас из `Admin.jsx`, переключение вкладок)
- `demo/auth.html` — вход, регистрация, ввод кода, сброс пароля, OAuth-consent (переключатель внизу)
- `package.json` — скрипты сборки

## Запуск
```
npm install
npm run build:css     # пересобрать dist/styles.css
```
Затем откройте `demo/index.html` в браузере (нужен интернет для Google Fonts).

## Как применить в другом проекте
Скопируйте `src/index.css` и `tailwind.config.js` (нужен плагин `tailwindcss-animate`),
подключите шрифты из STYLE-GUIDE.md и используйте классы как в `demo/index.html`.

## Что восстановлено, а не скопировано
- `AuthLayout` (оболочка страниц входа) и shadcn-компоненты `Button`, `Input`, `Label`, `InputOTP` — в файлах не было;
  сделаны по стандартным стилям shadcn на ваших токенах.
- Содержимое вкладок админки (`AdminLeads`, `AdminGallery`, `AdminCategories`, `AdminMaterials`, `AdminContent`) — не передавалось;
  таблица заявок и плитки галереи — пример в стиле сайта.
- `NAV_ITEMS` и `useReveal` — по логике компонентов.

## Что здесь заглушка
Контент секций на сайте приходит из базы (заголовки, тексты, преимущества, шаги, галерея,
контакты, материалы, направления), поэтому тексты и картинки в демо — примеры.
Изображения hero и «О компании» — те же Unsplash-ссылки, что в вашем коде; остальные — цветные заглушки.
React-компоненты и страницы в архив не входят — они у вас уже есть; их разметка продублирована в демо.
