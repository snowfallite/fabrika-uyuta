# ADR-0001: Слоты фото и шрифты по шаблону

**Status:** Proposed (применено в tech.md v2, ждёт подтверждения владельца)
**Date:** 2026-09-26
**Deciders:** владелец

## Context

Черновик приложения А писали до инвентаризации шаблона (S1-01). В `template/` оказались секция «Материалы» с двумя фото (ЛДСП, МДФ) и секция «О компании» с одним фото; секции «О производстве» нет. Текстовый шрифт шаблона Plus Jakarta Sans содержит только `cyrillic-ext`, русские буквы рисовал бы системный шрифт. Модели и API на момент решения ещё не существовали (до S1-04), поэтому контракт можно было поправить без миграций.

## Decision

- `SiteImageSlot`: `hero`, `about`, `material_ldsp`, `material_mdf`; `production` убран. `HomeSlots` следует слотам.
- Секция и якорь `materials` в карте главной и `NAV`.
- Текстовый шрифт Manrope (`@fontsource-variable/manrope`, есть `cyrillic`), заголовки Cormorant Garamond.

## Options Considered

### Option A: слоты по шаблону, Manrope (выбрано)
| Dimension | Assessment |
|-----------|------------|
| Complexity | Low: четыре слота вместо трёх, та же модель |
| Cost | Нет: до S1-04 кода не было |
| Scalability | Новый слот = значение enum и поле DTO |
| Team familiarity | Та же схема, что у остальных слотов |

**Pros:** вёрстка шаблона переносится один к одному; контент-менеджер меняет фото материалов в админке; русский текст одним шрифтом.
**Cons:** Manrope отличается от шаблона по рисунку; слоты «Материалы» завязаны на две фиксированные карточки.

### Option B: оставить черновик (`production`, Plus Jakarta Sans)
**Pros:** ноль правок ядра.
**Cons:** слот `production` негде показать; карточки материалов без фото; кириллица системным шрифтом.

## Trade-off Analysis

Шаблон главнее черновика (S1-01 для этого и существует). Правка до S1-04 ничего не ломает. Шрифт без кириллицы на русском сайте не проходит AC2 S1-01.

## Consequences

- Проще: секции главной один к одному повторяют шаблон.
- Сложнее: добавить третий материал = правка enum, миграция и DTO (через `CONTRACT GAP`).
- Пересмотреть: шрифт, если заказчик пришлёт фирменный с кириллицей.
